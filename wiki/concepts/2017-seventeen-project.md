# 2017 SEVENTEEN Project

## 一句話介紹
用「章節」包裝的回歸計畫，是 [Al1](../albums/al1.md) 和〈Don't Wanna Cry〉的故事框架。

## 章節
- **Chapter 0.5（序章）**：Al1 發行前，先推出一系列影片和三支副標為「Chapter 0.5 Before AL1」的 MV （來源：[Wikipedia 團體條目](../sources/wikipedia-seventeen-band.md)）
- **第一章**：〈Don't Wanna Cry〉MV，2017-05-22 公開 （來源：[Soompi 回歸報導](../sources/soompi-dont-wanna-cry-comeback.md)）

## 故事線
- WOOZI 說〈Don't Wanna Cry〉不是分手歌，而是延續上一張專輯裡的抒情曲〈Smile Flower〉的情緒 （來源：[Soompi 回歸報導](../sources/soompi-dont-wanna-cry-comeback.md)）
- ⚠️ Wikipedia 歌曲條目把歌詞描述為分手後的心碎，和 WOOZI 的說法衝突 （來源：[Wikipedia〈Don't Wanna Cry〉](../sources/wikipedia-dont-wanna-cry.md)）。wiki 以創作者本人的說法為主，兩種說法都保留。
- 待補：「上一張專輯」是否就是 [Going Seventeen](../albums/going-seventeen.md)；計畫是否還有第二章以後的作品
